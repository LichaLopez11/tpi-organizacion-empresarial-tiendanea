# TPI Organización Empresarial – TiendaNEA

**Módulo de Gestión de Inventario y Stock en Tiempo Real**

Trabajo Práctico Integrador y Progresivo de la asignatura **Organización Empresarial** – Tecnicatura Universitaria en Programación a Distancia (TUPaD) – Universidad Tecnológica Nacional.

## Descripción

TiendaNEA es una empresa ficticia de comercio electrónico que vende online productos regionales del Nordeste Argentino (yerba mate, artesanías, alimentos y textiles). El proyecto propone un módulo web que mantiene sincronizado en tiempo real el stock del depósito con el de la tienda online, para evitar ventas de productos sin disponibilidad y automatizar la reposición.
